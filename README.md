# Roll a Ball 
 
**Aluno:** Geovanna da Costa Gonçalves 
**Turma:** 2026.09.67 
**Feito com:** Unity 6 e C# 
 
## Sobre o projeto 
Você controla uma bolinha que está em um labirinto, o objetivo é pegar todos os quadrados  
 
## O que o projeto faz 
- o jogador movimenta a bolinha com as setas/WASD
- ao encostar nos , eles somem e o placar aumenta] 
- quando se coleta todos os quadrados, aparece a mensagem de vitória 
 
## O que o projeto contém 
- **Scripts:** CameraController, EnemyController, PlayerController, Rotator. 
- **Objetos principais:** Walls, Pick Up, Canvas, Enemy, player. 
- **Recursos usados:** MeshCollider, RigyBody, SphareCollider,TextMeshPRO, BoxCollider.
 
## Controles 
- W – vai pra frente, S - vai pra trás, A - vai pra esquerda, S - vai pra direita
